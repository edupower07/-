# 🚀 GAS（Google Apps Script）でのデプロイ手順

学校のタブレットから開けるWebアプリとして公開する手順です。
所要時間：約10分。

---

## 📋 必要なもの

- Googleアカウント（先生用）
- このフォルダの中身（`gas/` 内の全ファイル）

---

## 🛠 デプロイ手順

### 1. 新しいGASプロジェクトを作る

1. ブラウザで [https://script.google.com/](https://script.google.com/) を開く
2. 「**新しいプロジェクト**」をクリック
3. プロジェクト名を「**自動車づくりにはげむ人々**」に変更

### 2. ファイルを9個作成する

**左サイドバーの「ファイル」横の「+」ボタン**を使って、以下のファイルを作成します。

| ファイル名 | 種類 | 中身 |
|---|---|---|
| `Code.gs` | スクリプト（最初からある） | `gas/Code.gs` の中身をコピペ |
| `index` | HTML | `gas/index.html` の中身をコピペ |
| `koutei` | HTML | `gas/koutei.html` の中身をコピペ |
| `hito` | HTML | `gas/hito.html` の中身をコピペ |
| `buhin` | HTML | `gas/buhin.html` の中身をコピペ |
| `sekai` | HTML | `gas/sekai.html` の中身をコピペ |
| `kankyo` | HTML | `gas/kankyo.html` の中身をコピペ |
| `matome` | HTML | `gas/matome.html` の中身をコピペ |
| `stylesheet` | HTML | `gas/stylesheet.html` の中身をコピペ |
| `javascript` | HTML | `gas/javascript.html` の中身をコピペ |

> ⚠️ **注意**：HTMLファイル名に `.html` 拡張子は**書かない**でください。GASが自動的に付けます。

### 3. ウェブアプリとしてデプロイ

1. 右上の「**デプロイ**」→「**新しいデプロイ**」をクリック
2. 「種類の選択」（歯車アイコン）→「**ウェブアプリ**」を選択
3. 以下のように設定：
   - **説明**：「自動車学習サイト v1」など（自由）
   - **次のユーザーとして実行**：自分
   - **アクセスできるユーザー**：「**全員**」を選ぶ（子どもがログインなしで開けるように）
4. 「**デプロイ**」をクリック
5. 初回は「アクセスを承認」を求められるので、Googleアカウントで承認

### 4. URLを取得する

デプロイ完了後に表示される **「ウェブアプリ」URL** をコピーします。

例：
```
https://script.google.com/macros/s/AKfycbx.../exec
```

このURLを子どもたちのタブレットで開けば、サイトが表示されます！

---

## 🔄 修正したいとき

1. 該当ファイルを開いて編集
2. 「デプロイ」→「**デプロイを管理**」
3. 既存デプロイの右の鉛筆アイコンをクリック
4. 「バージョン」を「**新しいバージョン**」に変更
5. 「デプロイ」をクリック

> URLは変わりません（同じURLで最新版が表示されます）

---

## 💡 Tips

- **共有方法**：URLをGoogle ClassroomやQRコードにして配布すると便利
- **QRコード作成**：[https://www.qr-code-generator.com/](https://www.qr-code-generator.com/) などで簡単に作れる
- **学習データ保存**：メモ・クイズの結果はブラウザのlocalStorageに保存されるので、同じタブレット・同じブラウザなら次回も読み込まれる

---

## ❓ うまく動かないとき

| 症状 | 対処 |
|---|---|
| 「Authorization required」と出る | アクセスできるユーザーが「全員」になっているか確認 |
| ナビが効かない | HTMLファイル名（`koutei` など）が正しいか確認 |
| デザインが崩れる | `stylesheet` ファイルがあるか確認 |
| クイズが動かない | `javascript` ファイルがあるか確認 |

---

## 📦 代替案：Google Sitesに埋め込む

Google Sitesで使う場合：

1. 上記の手順でGASにデプロイし、URLを取得
2. Google Sitesの編集画面で「**埋め込む**」→「**URLで埋め込む**」
3. GASのURLを貼り付け
4. 完了！

GASのURLをiframeで埋め込む形になります。
